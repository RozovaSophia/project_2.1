# Проект "Домашнее задание к 09.06.2025"

## Описание:

Проект "Домашнее задание к 09.06.2025" - это пробная(учебная) программа, которая позволяет лучше понимать работу на 
PyCharm, Git, GitHub. Данный файл также дает больше понимания, как нужно строить описание проекта в рамках README. 
Текущий проект имеет четыре модуля - первый принимает счет или номер карты и маскирует их, второй выполняет
тот же функционал, но учитывает название, третий принимает список словарей с данными, которые фильтрует по 
данному ключу, а также сортирует данные по дате, и четвертый принимает список банковских транзакций,
фильтрует согласно установленному коду валюты, выводит описание каждой транзакции, а также генерирует 
номера карты в формате "ХХХХ ХХХХ ХХХХ ХХХХ", где диапазон вводит сам пользователь. В проекте существует 
декоратор, который записывает информацию о данных в отдельный файл или, если он не указан, 
выводит ее в консоль. Он обрабатывает ошибки и транслирует сообщения о них пользователю. В проект добавлена функция,
которая принимает данные из json файла и выводит сумму транзакции в рублях. Если валюта не соответствует заданному 
значению, то функция обращается к стороннему сервису через API и конвертирует валюту. В проект добавлена функция, 
которая ищет транзакцию по введенному слову в описании, а также считает количество описаний через библиотеку 
collections.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/RozovaSophia/project_2.1.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```
## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. Создайте новую запись в блоге или оставьте комментарий к существующей.

## Тестирование

Код успешно протестирован с помощью фреймворка Pytest. Запустить тестирование вы сможете через 
команду pytest, введенную в терминале, либо в PyCharm с помощью команды Run. Процент покрытия 
тестами кода - 90.
